# PHARM NOTE

약사를 위한 OTC 신제품 브리핑 및 전체 일반의약품 검색 웹앱.

## 현재 진행 상황
- [x] 1단계: 홈 화면 및 전체 디자인
- [x] 2단계: 전체 OTC 검색 및 데이터베이스
- [x] 3단계: 제품 상세 페이지
- [x] 4단계: 즐겨찾기 및 최근 본 제품
- [ ] 5단계: 주간 브리핑
- [ ] 6단계: 관리자 검토 시스템
- [ ] 7단계: AI 분석 초안 생성
- [ ] 8단계: GitHub Actions 자동화
- [ ] 9단계: GitHub Pages 배포 및 테스트

## 폴더 구조
```
index.html            홈 화면
pages/                나머지 화면 (브리핑, 검색, 즐겨찾기, 상세, 관리자)
data/                 앱이 읽는 데이터(JSON)
js/                   화면 동작 코드
styles/style.css      디자인
```

## 원칙
- 실제 출시가 확인되지 않은 제품은 신제품으로 표시하지 않는다.
- 식약처 공식 허가정보와 AI 분석은 항상 별도 영역에 표시한다.
- API 키·토큰은 코드에 넣지 않고 GitHub Secrets에만 보관한다.
